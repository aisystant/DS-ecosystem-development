# Неделя 3 — задание

**Цель недели:** применить метод медленного чтения не к абстрактному тексту, а к одному конкретному решению в рабочем проекте, которое требует сложного источника (документация, статья, регламент, чужой код).

**Метод недели:** выбрать один сложный источник, нужный для конкретного решения из списка РП недели. Прочитать медленно, с пометками и вопросами, а не пролистать; выйти с конкретным решением, не с общим «стало понятнее».

**Рабочий продукт недели (пример):** решение, принятое на основе источника, + короткая пометка, что из источника оказалось нужным.

**Критерий готовности:** решение можно объяснить со ссылкой на конкретное место источника, не общими словами.

**Свидетельство:** какой источник читали, какое решение приняли.

**Что принести на встречу:** решение и источник, случай, где чтение заняло больше времени, чем ожидали.
